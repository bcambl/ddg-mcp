# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in ddg-mcp, please report it privately.

**Do not open a public GitHub issue.**

Instead, use [GitHub's private vulnerability reporting](https://github.com/bcambl/ddg-mcp/security/advisories/new).

## What to include

- A description of the vulnerability
- Steps to reproduce
- The affected version(s)
- Any potential impact

## Response timeline

- Acknowledgment within 48 hours
- Initial assessment within 5 business days
- Fix or mitigation plan communicated within 10 business days

## Scope

This policy applies to the ddg-mcp codebase only. Vulnerabilities in DuckDuckGo's service or third-party dependencies should be reported to their respective maintainers.
